# Sanjoe Jose — Software Engineer & Full Stack Portfolio

An interactive, responsive developer portfolio showcasing software engineering projects, technical experience, and algorithmic optimizations. Built using **React**, **Tailwind CSS**, **React Router**, and **Lucide Icons**.

---

## 🚀 Key Features

* **Interactive Project Deep Dives**: Dedicated standalone routes (`/project/:id`) providing technical architectural overviews and problem-solution breakdowns.
* **Interactive WAYWIZ Setup Modal**: Step-by-step testing instructions, live faculty credentials, and enlarged scannable QR codes for testing the indoor navigation engine.
* **Algorithmic Case Study Highlights**: Detailed breakdown of floor-bypassing modified Dijkstra's algorithm optimization.
* **Theme Persistence**: Light and Dark mode toggle initialized to Light Mode with automatic browser `localStorage` state synchronization across routes.
* **Responsive Visual Elements**: CSS keyframe floating code window, glassmorphism terminal elements, and responsive layout scaling.

---

## 🛠️ Tech Stack

* **Frontend**: React (Vite), React Router DOM, Tailwind CSS
* **Icons**: Lucide React
* **Hosting Platform**: Vercel
* **Core Skills Displayed**: Java, Python, C/C++, React, Azure (ADF, Synapse, Fabric), Data Structures & Algorithms
